# Meta Ads 1.0.0

Initial Flow Steward integration for Facebook and Instagram advertising workflows.

## Workflow actions

Discover advertising accounts and Page/Instagram identities; select one advertising
account per project connection. Create website traffic campaigns and ad sets,
upload a square image artifact, create a single-image Feed creative and ad, read
status, and explicitly activate or pause one selected object. New campaign, ad-set
and ad objects are paused. Activation does not imply approval or actual delivery.

## Setup and compatibility

Requires the public extension host API1.9.0 or later and the atomic project
connection-config compare-and-set grant. The private release workflow verifies
published Core0.9.18 and the release owner's exact approved source/Core identities.
Use your own Meta app and project OAuth connection. Instagram placements require
an explicitly selected professional account linked to the selected Page.

Both Linux AMD64 and ARM64 ZIPs contain only their matching hash-locked Pillow
wheel. The icon identifies Flow Steward, the independent publisher; it is not
Meta, Facebook or Instagram artwork or an endorsement.

## Acceptance limits

Live OAuth, real Meta permissions/accounts/assets and paused-object acceptance
have not been verified: the owner deferred these checks. Offline tests and native
archive installation do not certify advertising delivery. Video, carousel,
organic posting, reporting, custom audiences, campaign budgets and special
advertising categories are outside this version.

This is a release in a private repository. Public availability and public catalog
registration remain separate owner-controlled steps. There is no previous stable
Meta Ads release or previous-tag comparison for this initial version.
