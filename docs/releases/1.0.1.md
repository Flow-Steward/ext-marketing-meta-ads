# Meta Ads 1.0.1

Adds an original violet campaign/megaphone icon so Meta Ads is recognizable in
the extension catalog. This independent Flow Steward artwork does not use the
Meta, Facebook or Instagram marks or imply their endorsement. Artwork provenance
and the exact icon hash are included in both native archives.

The listing now identifies this publicly available reference extension. Runtime,
permissions, OAuth configuration, dependency locks and advertising behavior are
unchanged from 1.0.0. Public release publication uses the shared CI publisher.
Both Linux AMD64 and ARM64 archives are built and validated through hosted CI.

Requires extension host API 1.9.0 and the atomic project connection-config
compare-and-set grant; compatibility remains the same as 1.0.0. New advertising
objects remain paused. Live Meta OAuth and advertising-object acceptance remain
unverified and deferred by the owner. This artwork release does not certify
provider permissions, ad approval or delivery.
