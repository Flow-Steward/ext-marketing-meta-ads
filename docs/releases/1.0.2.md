# Meta Ads 1.0.2

Updates the bundled Pillow dependency to 13.0.0 on Linux AMD64 and ARM64.
Both image-validation passes now select only JPEG and PNG decoders before
opening user-provided data. The existing 5 MiB limit, single-frame 1080 x 1080
requirement, full decode validation and original upload bytes are preserved.

Workflow actions, permissions, connection grants and OAuth configuration retain
the 1.0.1 contract. Hosted CI checks malformed and unsupported images and verifies
valid JPEG/PNG processing from each native, offline-installed release archive.
Live Meta account operations are not exercised by these offline checks.
