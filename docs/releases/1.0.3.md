# Meta Ads 1.0.3

Adds a global **Support** page with links to report a problem, ask a question,
request a feature, browse existing issues and read this extension’s documentation
and source code. It is available without selecting a project connection.

The page explains which versions, expected and actual behavior, error message,
workflow context and time to include. It points to **Monitoring → Download
diagnostics** and reminds users to review diagnostics and omit secrets and customer
data from public issues. Manifest and descriptor support links use the same issue
tracker.

The Pillow 13.0.0 dependency, JPEG/PNG decoder restriction, workflow actions,
permissions, connection grants, OAuth configuration and icon are unchanged from
1.0.2. Hosted source and native archive checks cover Support registration and
bundle contents; live Meta OAuth and advertising operations remain unverified.
